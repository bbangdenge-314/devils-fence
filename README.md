# 울타리 치기 · DEVIL'S FENCE

넷플릭스 「데블스 플랜 3」 유배지 매치에 나온 **울타리 치기(Slitherlink, 슬리더링크)** 를 웹에서 바로 즐기는 게임입니다.
점과 점 사이에 선(울타리)을 그어, 모든 숫자를 만족시키면서 **단 하나의 닫힌 고리**를 완성하면 클리어입니다.

**플레이:** https://bbangdenge-314.github.io/devils-fence/

- 빌드 도구 없음 — 순수 HTML/CSS/JS 정적 사이트 (GitHub Pages `main` / 루트)
- PC 마우스 · 모바일 터치 모두 지원, 모든 퍼즐은 **유일해 검증**을 통과한 판만 출제

---

## 규칙

1. **숫자만큼 선을 긋는다** — 칸 안의 숫자(0~3)는 그 칸을 둘러싼 울타리 선의 개수입니다.
2. **선은 하나의 닫힌 고리** — 모든 선은 끊김·갈라짐·교차 없이 하나로 이어진 고리를 이뤄야 합니다.
3. **한 점에서는 0개 또는 2개** — 격자의 한 점에 선이 모이는 개수는 0개 아니면 2개입니다.

## 플레이 방법

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 변 순환 (빈 → 선 → X → 빈) | 클릭 | 탭 |
| 바로 X 표시 | 우클릭 | `X` 모드 선택 후 탭 |
| 여러 변 한 번에 긋기 | 드래그 | 드래그 |
| 되돌리기 / 다시 실행 | `Ctrl+Z` / `Ctrl+Shift+Z` | 툴바 버튼 |
| 논리 힌트 | `H` / 💡 버튼 | 💡 버튼 |

- **입력 모드**: `자동`(순환) · `선` · `X` · `지우개`
- **분기 저장(📌)/분기 복원(↩️)**: 어려운 판에서 특정 배치를 가정하고 밀어붙이다 모순이 나오면 저장 시점으로 즉시 되돌립니다.
- **스마트 힌트**: 정답을 찍어 주는 대신 실제 슬리더링크 논리(0 주변 X, 숫자 완성, 출구 하나, 가정 시 모순 등)를 찾아 **이유를 한국어로 설명**하고 해당 변을 하이라이트합니다. 필요하면 `적용`으로 바로 반영할 수 있습니다.
- **실시간 피드백**: 숫자가 채워지면 완료 강조, 넘치면 경고. `⚙️ 옵션`에서 경고를 끄면 방송 실전 하드코어 모드가 됩니다.
- **자동 클리어**: 다음 네 가지를 **모두** 만족할 때만 클리어됩니다.
  1. 모든 숫자 단서가 정확히 일치
  2. 모든 교차점의 선 개수가 0개 또는 2개 (끊긴 끝 1개, 갈라짐 3개 이상은 불가)
  3. 선 전체가 **단 하나의 연결 요소**(닫힌 고리 하나) — 고리가 둘로 나뉘면 클리어 아님
  4. 선이 하나 이상

  숫자는 다 맞았는데 울타리가 끊겨 있으면, 끊긴 교차점을 금색으로 짚어 줍니다. 클리어된 판은 더 이상 되돌리기·복원·초기화로 바뀌지 않습니다.

## 게임 모드

### 유배지 챌린지 (스테이지)
| # | 이름 | 크기 | 난이도 |
| --- | --- | --- | --- |
| 1 | 수련의 방 | 5 × 5 | 입문 |
| 2 | 유배지 예선 | 7 × 7 | 기본 |
| 3 | 유배지 본선 | 10 × 10 | 심화 |
| 4 | 심연의 문 | 12 × 12 | 고난도 |
| 5 | 신의 시험 | 15 × 15 | 최종 |

앞 스테이지를 클리어해야 다음 문이 열리고, 스테이지별 최고 기록은 `localStorage`에 저장됩니다. 진행 중인 판은 자동 저장되어 홈의 **이어하기**로 돌아올 수 있습니다.

### 자유 플레이
크기 `5×5 · 7×7 · 10×10 · 12×12 · 15×15` × 난이도 `쉬움 · 보통 · 어려움`.
5×5~10×10은 실행 중 즉석 생성하고, 12×12·15×15는 빌드 시점에 만들어 검증해 둔 퍼즐 풀에서 출제합니다.

## 퍼즐 생성과 유일해 검증

`js/generator.js`

1. **무작위 단일 폐곡선 생성** — 격자 위 작은 사각형에서 시작해, 고리를 깨지 않는 "범프(bump)" 확장을 반복합니다. 매 확장마다 연결 요소가 1개인지 확인해 고리가 쪼개지지 않게 합니다.
2. **단서 도출** — 각 칸을 둘러싼 선의 개수를 숫자로 기록합니다.
3. **단서 제거 + 유일해 검증** — 단서를 무작위 순서로 하나씩 지우고, 지울 때마다 내장 솔버(`js/solver.js`)로 해의 개수를 세어 **정확히 1개일 때만** 제거를 확정합니다. 난이도는 남기는 단서 밀도와 "기본 전파만으로 풀리는지"로 조절합니다.

솔버는 제약 전파(칸 숫자 · 교차점 차수) + 조합 분기 DFS에 다음 가지치기를 더했습니다.

- 닫힌 고리가 생겼는데 아직 채워야 할 단서가 남아 있으면 모순
- 선도 단서도 없는 빈 영역은 모두 X (탐색 폭발 방지)
- 교차점 차수 3 이상, 막다른 끝, 숫자 초과/부족 즉시 모순

### 검증 스크립트

```bash
# 클리어 판정 회귀 테스트 (끊긴 끝·분리된 고리·T자 갈라짐은 절대 클리어 아님 + 실제 화면 확인)
python3 verify/win_rule_test.py

# 배포된 라이브 사이트 최종 검증 (홈 → 스테이지 → 플레이 → 클리어)
python3 verify/live_test.py

# 저장된 스테이지·뱅크 퍼즐 전체를 파이썬 독립 솔버로 재검증
python3 verify/verify.py --presets

# 브라우저에서 새로 생성한 퍼즐을 파이썬 솔버로 교차 검증(5×5~15×15 × 3난이도)
python3 verify/verify.py --gen-only

# 실제 플레이 검증(PC 1440×900 / 모바일 390×844 hasTouch) + 대표 스크린샷
python3 verify/ui_test.py
```

`verify/verify.py`는 JS 생성기와 **별도로 구현한 파이썬 솔버**로
① 저장된 해답이 규칙을 만족하는지 ② 그 해답이 유일한지 를 모두 확인합니다.
`verify/ui_test.py`는 클릭 순환·우클릭 X·드래그 연속 입력·되돌리기/다시 실행·힌트·분기 저장/복원·
자동 클리어·레이아웃 비겹침·콘솔 오류 0건을 실제 브라우저에서 검사합니다.
